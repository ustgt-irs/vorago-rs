# Vorago Flashloader Client

Client for the flashloaders of the [VA108xx](../../va108xx/flashloader/README.md) and the
[VA416xx](../../va416xx/flashloader/README.md).

The chip and the serial port are read from `loader.toml` in the current directory. You can also
pass them with `--chip` and `--port`. Run `cargo run -- -h` for an overview of all commands.
